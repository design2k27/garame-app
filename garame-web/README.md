
  # High-Fidelity UI/UX Design

  This is a code bundle for High-Fidelity UI/UX Design. The original project is available at https://www.figma.com/design/hzs6NYqMQkYg936NqAqrrb/High-Fidelity-UI-UX-Design.

  ## Configuration

  The front reads the API base URL from `.env`:

  ```env
  VITE_API_BASE_URL=https://garame-api.103.13.211.56.nip.io
  ```

  Copy `.env.example` to `.env.local` if you need a local override.

  ## Running the code

  Run `pnpm install` to install the dependencies.

  Run `pnpm run dev` to start the development server.
